# Getting Started

`proxy-wasm-host` is a Rust implementation of the [proxy-wasm](https://github.com/proxy-wasm/spec) specification.

It is a port of the [proxy-wasm-go-host](https://github.com/mosn/proxy-wasm-go-host).
Unlike the original, it only supports version 2.0 of the spec onward and has far more tests.
